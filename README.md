# LLM-Mini-Harness
This is the first part of a project for ECE 309. In this project, vibe coding was utilized to create a mock LLM agent harness, which is a way that the LLM interacts with the user through managing the various needs of the user: tokens, inputs, and context windows for example. Prompting LLMs was learned and practiced. Ensuring that the LLM provided valid output was also practiced. To use this, first use "gcc harness.c -o harness" in a WSL in VS code or within a terminal of either a Mac or Linux. In addition, ensure that valgrind is installed using "sudo apt update && sudo apt install valgrind." After this, type ./harness and wait. Now type what you want. If you type a sentence or prompt that contains "hello", then you will receive a hardcoded greeting. Any other input is mirrored in output. Type exit to close out of the program. The bash script will  check for memory leaks and for errors.
